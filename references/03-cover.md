# 阶段三：视频封面（横屏 16:9 + 竖屏 9:16）

封面用“版式参考图 + 图像编辑换文字”的方式生产，保证形象与整套视觉一致，文字逐字准确。

## 1. 统一视觉

- 背景：浅米白 → 浅青蓝柔和渐变，低饱和，不要高饱和蓝紫。
- 人物：固定账号卡通形象（黑框眼镜、棕卷发、橙色连帽衫、橙白发光耳机、微笑），全系列同一形象，不要每次重绘成不同人。
- 标题：深蓝黑超大粗体无衬线；标题下一条蓝色短横线；标签为蓝色描边（横屏）或蓝色实心（竖屏）圆角胶囊；卖点一行灰色小字。

## 2. 横屏 16:9（B站/视频号横版/YouTube）

- 右侧：形象半身像；左侧：文案区。
- 左上蓝色描边胶囊标签（如“AI工具深度测评”）。
- 左侧两行超大粗体主标题，其下蓝色短横线，再下一行灰色卖点小字。

## 3. 竖屏 9:16（抖音/视频号竖版/Shorts）

- 上半：浅蓝渐变 + 一道柔和圆弧切出形象半身；下半：白色文案区。
- 蓝色实心胶囊标签；三行超大粗体标题；蓝色短横线；灰色卖点小字。

## 4. 生产方式（image_edit 锚点替换）

1. 选一张本系列已确认满意的封面作为版式/形象锚点，上传取 URL。
2. 图像编辑指令只改文字，明确要求“完全保留版式、渐变、人物形象与标签样式，删除旧文案，不要出现旧产品名”。
3. 主标题、卖点逐字写进指令；生成后回读核对：无错别字、无旧产品名残留、形象未漂移。
4. 横、竖分别独立生成，比例分别锁定 16:9 与 9:16，不要拉伸。

## 5. 封面文案要点

- 主标题给钩子（反常识/数字/身份共鸣），卖点一行补“怎么做”。
- 一页只留一个主标题 + 一行卖点，不堆关键词。
